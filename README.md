## Run locally

This is a static website. You can open `index.html` directly in a browser, or serve the folder with a local development server.

For example, if Python is installed:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Deploy with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch** if that is the configured deployment method.
3. Select the `main` branch and the `/(root)` folder, then save.
4. Wait for the Pages deployment workflow to finish.
5. Open the published URL in a private/incognito window or on a device that is not signed in to GitHub.

Repository: https://github.com/Emmy1-tech/Portfolio  
Expected project-site URL: https://emmy1-tech.github.io/Portfolio/

If the page returns a 404, confirm the Pages source and check the latest deployment under the repository's **Actions** tab. A successful workflow is useful evidence, but the final URL still needs to be opened and tested.
