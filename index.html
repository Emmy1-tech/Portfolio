CloudPulse — front end, API, and data flow

The problem and workflow

A dashboard for exploring endpoint inventory and incident handling. Register a sample endpoint, trigger a simulated failed check, inspect its stored history, acknowledge the resulting incident, and resolve it.

The implementation

The React/TypeScript interface calls a shared Axios API client. In local backend mode, FastAPI validates payloads with Pydantic and uses request-scoped SQLAlchemy sessions to persist endpoints, check results, and incidents in SQLite. The public demo uses browser-local sample data instead.

A decision worth discussing

The configured API layer can select a demo adapter or the backend adapter. This makes the public UI explorable without exposing the unfinished API. Repeated simulated failures reuse an existing open or acknowledged incident rather than creating a duplicate active incident.

Current scope: checks and metrics are simulated. There is no automatic check scheduler or production authentication/user isolation. Test code and CI configuration are available to inspect; linked workflow runs show their current results.

AI Career Copilot — user workflows and Express APIs

The problem and workflow

A career workspace that brings resume feedback, application tracking, job-description comparison, and interview practice into one interface.

The implementation

A browser-native HTML/CSS/JavaScript front end talks to an Express API. A local JSON store queues mutations and writes through a temporary file before replacement. Gemini integration runs on the server when configured; rules-based feedback is labelled clearly when it is used.

Evidence to inspect

API tests cover the application lifecycle, invalid job URLs and statuses, malformed or oversized JSON, unavailable AI configuration, provider failures/timeouts, request limits, and concurrent local writes. The CI matrix targets Node.js 20 and 22.

Current scope: job listings are samples. The demo has no sign-in or private per-user data isolation, and JSON storage is not durable on its current host. Explore with fictional information. AI features depend on server configuration.
